One letter for the day: **K** — knackered.

- `main.ts` — the entrypoint. It writes the single letter `K` to
  `/output/entry.txt`, exactly one character, nothing else.
- The letter stands for "knackered": bone-tired, wiped out, running on
  fumes after a day that took everything. Vivid, funny, and true — and K
  is the word's own initial, the hard sound matching the word's punch.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` containing `K`.
